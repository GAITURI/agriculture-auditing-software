# SCIPEC Operations: frontend

HTML5 + Bootstrap 5 + Tailwind CSS (prefix `tw-`) + vanilla ES modules. See the root `README.md` for Windows run steps and `MIGRATION_REPORT.md` for what changed and what was tested.

    npm install
    npm run build   # vendor/ (Bootstrap) + css/styles.css (Tailwind)
    npm start       # http://127.0.0.1:5173
